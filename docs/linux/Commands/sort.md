# sort

Sort lines of text files.

## Syntax

```bash
sort [options] [file]
```

## Common Usage

```bash
sort file.txt
```

```bash
sort -u file.txt
```

```bash
sort -k2 -t: file.txt
```

```bash
sort -hr
```

## Tips

- -u for unique, -k for key column, -t for delimiter, -r reverse, -h human numeric
