# diff

Compare files line by line.

## Syntax

```bash
diff [options] file1 file2
```

## Common Usage

```bash
diff file1 file2
```

```bash
diff -u file1 file2
```

```bash
diff -rq dir1/ dir2/
```

## Tips

- -u for unified format, -r for recursive, -q for brief (files differ?)
