# cd

Change the current working directory.

## Syntax

```bash
cd [directory]
```

## Common Usage

```bash
cd ~
```

```bash
cd -
```

```bash
cd ../..
```

```bash
cd /var/log
```

## Tips

- cd - returns to previous directory, cd ~ goes home
