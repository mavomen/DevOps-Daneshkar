# ls

List directory contents.

## Syntax

```bash
ls [options] [path]
```

## Common Usage

```bash
ls -la
```

```bash
ls -lh /var
```

```bash
ls -lt | head
```

```bash
ls -R src/
```

## Tips

- Use -l for long format, -a for hidden files, -h for human sizes, -t for sort by time
