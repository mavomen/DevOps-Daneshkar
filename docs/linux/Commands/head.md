# head

Output the first lines of a file.

## Syntax

```bash
head [options] [file]
```

## Common Usage

```bash
head -20 file.txt
```

```bash
head -n 5 /etc/passwd
```

```bash
head -c 100 file.txt
```

## Tips

- -n for lines, -c for bytes. Default is 10 lines
