# mkdir

Create directories.

## Syntax

```bash
mkdir [options] dir...
```

## Common Usage

```bash
mkdir project
```

```bash
mkdir -p a/b/c
```

```bash
mkdir -m 700 secure
```

## Tips

- -p creates parent directories, -m sets permissions
