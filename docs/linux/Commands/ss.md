# ss

Socket statistics (replaces netstat).

## Syntax

```bash
ss [options]
```

## Common Usage

```bash
ss -tlnp
```

```bash
ss -tnp
```

```bash
ss -s
```

```bash
ss -ulnp
```

## Tips

- -t TCP, -u UDP, -l listening, -n numeric, -p with process, -s summary
