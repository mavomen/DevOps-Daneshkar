# echo

Display a line of text.

## Syntax

```bash
echo [options] [string]
```

## Common Usage

```bash
echo 'Hello World'
```

```bash
echo $PATH
```

```bash
echo -e 'line1
line2'
```

```bash
echo 'text' >> file.txt
```

## Tips

- -e enables escape sequences (\n, \t), -n suppresses newline
