# cp

Copy files and directories.

## Syntax

```bash
cp [options] source dest
```

## Common Usage

```bash
cp file.txt backup.txt
```

```bash
cp -r dir/ backup/
```

```bash
cp -a dir/ backup/
```

```bash
cp -i file.txt dest/
```

## Tips

- Use -r for directories, -a for archive (preserves all attributes), -i for interactive
