# touch

Create empty files or update timestamps.

## Syntax

```bash
touch [options] file...
```

## Common Usage

```bash
touch newfile.txt
```

```bash
touch -t 202501011200 file
```

```bash
touch file{1..10}.txt
```

## Tips

- Creates file if it doesn't exist, updates timestamp if it does
