# top

Display running processes in real-time.

## Syntax

```bash
top [options]
```

## Common Usage

```bash
top
```

```bash
top -u www-data
```

```bash
top -bn1 | head -20
```

## Tips

- Press M to sort by memory, P by CPU, k to kill, q to quit
