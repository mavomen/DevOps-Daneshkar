# mv

Move or rename files and directories.

## Syntax

```bash
mv [options] source dest
```

## Common Usage

```bash
mv old.txt new.txt
```

```bash
mv file.txt /tmp/
```

```bash
mv -i file.txt dest/
```

```bash
mv *.jpg /photos/
```

## Tips

- Also used for renaming, -i prompts before overwrite
