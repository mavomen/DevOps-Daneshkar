# fdisk

Partition table manipulator.

## Syntax

```bash
fdisk [options] device
```

## Common Usage

```bash
fdisk -l
```

```bash
fdisk /dev/sdb
```

```bash
lsblk
```

## Tips

- Interactive menu. Use 'n' for new partition, 'w' to write, 'q' to quit
