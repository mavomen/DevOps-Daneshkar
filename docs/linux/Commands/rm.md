# rm

Remove files and directories.

## Syntax

```bash
rm [options] file...
```

## Common Usage

```bash
rm file.txt
```

```bash
rm -rf dir/
```

```bash
rm -i *.log
```

```bash
rm -- -filename
```

## Tips

- -r for directories, -f to force, -i for interactive. There is no undo!
