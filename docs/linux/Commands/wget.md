# wget

Download files from the web.

## Syntax

```bash
wget [options] URL
```

## Common Usage

```bash
wget https://example.com/file.zip
```

```bash
wget -c URL
```

```bash
wget -r URL
```

## Tips

- -c for continue, -r for recursive, -q for quiet
