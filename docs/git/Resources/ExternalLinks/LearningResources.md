# Learning Resources

Beginner-friendly and intermediate resources that build solid Git fundamentals.

## Books / Guides

- Pro Git (free): https://git-scm.com/book/en/v2
- Atlassian Git Tutorials: https://www.atlassian.com/git/tutorials

## Practice / Sandboxes

- Learn Git Branching (interactive): https://learngitbranching.js.org/

## Topics to focus on (order suggestion)

1. Basics:
   - working tree vs staging area vs commit
   - `git add`, `git commit`, `git status`, `git diff`
2. Branching:
   - `git switch`, `git merge`, `git rebase` (conceptually)
3. Remotes:
   - `origin`, upstream tracking, `fetch` vs `pull`
4. Recovery:
   - `git reflog`, safe undo with `git revert`
