## How to ask good Git questions

Include:

- exact command(s) you ran
- exact output/error
- what you expected vs what happened
- repo state:
  - `git status -sb`
  - `git log --oneline --decorate --graph -n 30 --all`
  - `git remote -v`
  - `git branch -vv`
