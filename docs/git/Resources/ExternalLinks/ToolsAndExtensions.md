# Tools and Extensions

Popular tools that complement Git. Choose what matches your workflow and team policies.

## GUI clients

- GitHub Desktop: https://desktop.github.com/
- Sourcetree (Atlassian): https://www.sourcetreeapp.com/
- GitKraken: https://www.gitkraken.com/

## CLI helpers

- Git LFS (large files): https://git-lfs.com/
- pre-commit framework (multi-language hooks): https://pre-commit.com/

## Editors / IDE integrations

- VS Code source control: https://code.visualstudio.com/docs/sourcecontrol/overview
- JetBrains Git integration: https://www.jetbrains.com/help/

## CI/CD tooling docs

- GitHub Actions: https://docs.github.com/en/actions
- GitLab CI/CD: https://docs.gitlab.com/ee/ci/

## Suggested usage guidance

- Prefer CLI knowledge even if you use a GUI (helps debugging)
- Ensure team agreement before introducing:
  - Git LFS
  - submodules
  - history rewriting workflows
