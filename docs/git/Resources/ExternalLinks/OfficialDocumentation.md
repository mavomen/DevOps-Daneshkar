# Official Documentation

A curated list of official docs for Git and common Git platforms.

## Git (official)

- Git project home: https://git-scm.com/
- Git documentation: https://git-scm.com/docs
- Pro Git book (officially hosted): https://git-scm.com/book/en/v2
- Git release notes: https://github.com/git/git/blob/master/Documentation/RelNotes

## GitHub (official)

- GitHub Docs: https://docs.github.com/
- Pull Requests: https://docs.github.com/en/pull-requests
- GitHub Actions: https://docs.github.com/en/actions

## GitLab (official)

- GitLab Docs: https://docs.gitlab.com/
- Merge requests: https://docs.gitlab.com/ee/user/project/merge_requests/
- GitLab CI/CD: https://docs.gitlab.com/ee/ci/

## Bitbucket / Atlassian (official)

- Bitbucket Cloud Docs: https://support.atlassian.com/bitbucket-cloud/
- Atlassian Git tutorials: https://www.atlassian.com/git/tutorials

## SSH (official)

- OpenSSH manual pages (portable): https://www.openssh.com/manual.html

## Suggested “starting points” (if you’re overwhelmed)

- Start with Pro Git: https://git-scm.com/book/en/v2
- Then: `git` command reference: https://git-scm.com/docs
