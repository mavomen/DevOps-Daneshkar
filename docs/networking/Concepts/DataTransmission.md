# Data Transmission

Data transmission is the transfer of data between devices over a communication medium.

## Guided media (wired)

| Medium | Speed | Distance | Use case |
|---|---|---|---|
| Twisted pair (Cat5e/Cat6) | 1 Gbps – 10 Gbps | 100m | LAN, Ethernet |
| Coaxial cable | 10 Gbps | 500m | Cable internet, CCTV |
| Fiber optic | 100 Gbps+ | 100km+ | Backbone, data centers |
| PCB traces | Varies | mm–cm | On-board communication |

## Unguided media (wireless)

| Medium | Range | Use case |
|---|---|---|
| Radio waves (Wi-Fi) | 10–100m | WLAN |
| Bluetooth | 10m | Peripheral devices |
| Microwave | Line of sight | Point-to-point links |
| Satellite | Global | Remote areas |

## Signal types

| Type | Description |
|---|---|
| Analog | Continuous wave (e.g., sound, old phone lines) |
| Digital | Discrete 0/1 signals (e.g., Ethernet, Wi-Fi) |

## Modem

A modem performs modulation and demodulation:
- **Modulation**: Digital → analog (for transmission over analog medium)
- **Demodulation**: Analog → digital (for reception)
