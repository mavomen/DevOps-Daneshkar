# Bandwidth and Throughput

Two related but different measures of network performance.

## Bandwidth

The **maximum** data transfer rate of a network link. Theoretical capacity.

| Unit | Value |
|---|---|
| Kbps | Kilobits per second (10³) |
| Mbps | Megabits per second (10⁶) |
| Gbps | Gigabits per second (10⁹) |
| Tbps | Terabits per second (10¹²) |

## Throughput

The **actual** data transfer rate achieved. Real-world performance after overhead, congestion, and packet loss.

## Bandwidth vs Throughput

| | Bandwidth | Throughput |
|---|---|---|
| Meaning | Maximum possible | Actual achieved |
| Measured by | Provider spec | Speed tests, monitoring |
| Affected by | Link capacity | Congestion, latency, errors |
